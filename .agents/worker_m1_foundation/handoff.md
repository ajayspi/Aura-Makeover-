## 2. Logic Chain

1. **Resolution of TypeScript Typing Error**:
   - `RootLayout` in `src/app/layout.tsx` was parameter-typed with non-existent `LayoutProps<"/">`.
   - Replacing this with `Readonly<{ children: React.ReactNode }>` uses canonical React 19 / Next.js 16 typing and resolves TS2304 compile errors.
2. **Font Loading Architecture**:
   - `Syne` and `Plus_Jakarta_Sans` are initialized via `next/font/google` with CSS variable definitions (`--font-syne`, `--font-plus-jakarta-sans`), subsets `["latin"]`, and specified weights (`700`, `800` for Syne; `400`, `500`, `600`, `700`, `800` for Plus Jakarta Sans).
   - In addition, an explicit `@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&family=Syne:wght@700;800&display=swap');` in `globals.css` guarantees that literal `font-['Syne']` and `font-['Plus_Jakarta_Sans']` classes used throughout the component library evaluate properly in both standard CSS and Tailwind arbitrary value contexts.
3. **Tailwind CSS v4 `@theme` Design System Tokens**:
   - Defined custom font tokens (`--font-syne`, `--font-sans`, `--font-jakarta`) and color tokens (`--color-espresso`, `--color-gold`, `--color-terracotta`, `--color-linen`, `--color-whatsapp`).
   - Tailwind v4 automatically exposes utility classes: `bg-espresso`, `text-espresso`, `bg-gold`, `text-gold`, `bg-terracotta`, `text-terracotta`, `bg-linen`, `text-linen`, `bg-whatsapp`, `font-syne`, `font-sans`, `font-jakarta`.
4. **Theme and Typography Enforcement**:
   - Removed the dark-mode media query override so the linen off-white `#FAF8F5` background remains consistent across all operating system color scheme preferences.
   - Set `:root` and `body` to background `#FAF8F5` and color `#1C130B`.
   - Applied `font-family: 'Syne', var(--font-syne), sans-serif;` to all heading tags `h1, h2, h3, h4, h5, h6` so every section heading automatically adopts the luxury editorial display font.
