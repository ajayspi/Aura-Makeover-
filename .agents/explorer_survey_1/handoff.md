## 2. Logic Chain

### 2.1 Resolving the TypeScript Compilation Failure in `layout.tsx`
- **Observation**: `layout.tsx:20` declares `RootLayout({ children }: LayoutProps<"/">)`. `LayoutProps` is undeclared.
- **Reasoning**: Next.js App Router root layout takes `{ children: React.ReactNode }` or `Readonly<{ children: React.ReactNode }>`.
- **Solution**:
  ```tsx
  export default function RootLayout({
    children,
  }: Readonly<{
    children: React.ReactNode;
  }>) {
  ```
- This directly satisfies acceptance criteria:
  `No 'LayoutProps<"/">' TypeScript usage anywhere in the codebase` and ensures `tsc --noEmit` passes.

### 2.2 Google Fonts Strategy for Next.js 15/16 + Tailwind CSS v4
- **Observation**: The app uses `font-['Syne']` for headings and `font-['Plus_Jakarta_Sans']` for body, but neither font is imported, and `body` in `globals.css` falls back to `Arial, Helvetica, sans-serif`.
- **Reasoning**:
  1. `next/font/google` provides zero-layout-shift, self-hosted font loading with Next.js build-time font optimization.
  2. Tailwind CSS v4 `@theme` generates utility classes like `font-syne` and `font-jakarta`.
  3. Existing components in `src/components/` and user acceptance criteria use arbitrary utility syntax: `font-['Syne']` and `font-['Plus_Jakarta_Sans']`.
  4. An `@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&family=Syne:wght@700;800&display=swap');` in `globals.css` guarantees that literal `font-family: 'Syne'` and `font-family: 'Plus Jakarta Sans'` resolve in the browser regardless of whether a component uses `@theme` utilities (`font-syne`) or arbitrary utilities (`font-['Syne']`).
- **Solution**:
  1. In `src/app/layout.tsx`:
     ```tsx
     import { Syne, Plus_Jakarta_Sans } from "next/font/google";

     const syne = Syne({
       variable: "--font-syne",
       subsets: ["latin"],
       weight: ["700", "800"],
       display: "swap",
     });

     const plusJakartaSans = Plus_Jakarta_Sans({
       variable: "--font-plus-jakarta-sans",
       subsets: ["latin"],
       weight: ["400", "500", "600", "700", "800"],
       display: "swap",
     });
     ```
     Attach to `html`:
     ```tsx
     <html lang="en" className={`${syne.variable} ${plusJakartaSans.variable} h-full antialiased`}>
     ```
  2. In `src/app/globals.css`:
     Add the Google Fonts web import at the top, configure `@theme`, and define global typography:
     ```css
     @import "tailwindcss";
     @import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&family=Syne:wght@700;800&display=swap');

     @theme {
       --font-syne: 'Syne', var(--font-syne), sans-serif;
       --font-sans: 'Plus Jakarta Sans', var(--font-plus-jakarta-sans), sans-serif;
       --font-jakarta: 'Plus Jakarta Sans', var(--font-plus-jakarta-sans), sans-serif;

       --color-espresso: #1C130B;
       --color-gold: #C5A880;
       --color-terracotta: #8A5836;
       --color-linen: #FAF8F5;
       --color-whatsapp: #15803D;
     }

     :root {
       --background: #FAF8F5;
       --foreground: #1C130B;
     }

     body {
       background-color: #FAF8F5;
       color: #1C130B;
       font-family: 'Plus Jakarta Sans', var(--font-plus-jakarta-sans), sans-serif;
     }

     h1, h2, h3, h4, h5, h6 {
       font-family: 'Syne', var(--font-syne), sans-serif;
     }
     ```
